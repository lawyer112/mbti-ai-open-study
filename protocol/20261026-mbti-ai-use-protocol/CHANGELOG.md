首次公开方案包：补齐完整中英全文、共享参考文献、论断证据、术语表、同源网页/PDF和核验记录。增加研究问题与题目映射，明确正式阶段主要探索指标为外部核验，区分行为关联与客观绩效研究。问卷题意维持中文v0.2；导出补充中文语言和试填阶段标记，并接入真实回传入口。无真人结果发表。

First public protocol package: complete Chinese and English texts, shared references, an evidence record, glossary, HTML/PDF from the same sources, and verification records. Added the research-question/item mapping, specified external verification as the intended primary exploratory outcome, and separated behavioral associations from objective performance research. Instrument wording remains Chinese v0.2; exports add language and pilot-stage metadata and use the actual return pathway. No human-participant findings are published.
