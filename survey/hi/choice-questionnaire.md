# MBTI × AI: आपका AI साथी कैसा है? · झटपट विकल्प v0.3

MBTI, रोज़मर्रा के AI इस्तेमाल, विचारों और अनुभवों पर अनौपचारिक सर्वेक्षण। पिछले 30 दिनों के बारे में सोचें। यह व्यक्तित्व परीक्षण या क्षमता की रैंकिंग नहीं है।

पिछले 30 दिनों की आदतों और विचारों के बारे में सोचें। किसी पूरे काम को दोबारा विस्तार से बताना ज़रूरी नहीं। हाल में AI इस्तेमाल न करने वाले भी भाग ले सकते हैं।

इस पढ़ने योग्य फ़ॉर्म में सभी सवालों के उद्देश्य दिखते हैं। जमा करते समय यह दर्ज करें कि आपने इन्हें देखा।

## GitHub से भेजें

रिपोर्ट जाँचें और सार्वजनिक न की जाने वाली सामग्री हटाएँ।
JSON डेटा और पढ़ने योग्य Markdown रिपोर्ट डाउनलोड करें।
GitHub Issue में फ़ाइलें लगाएँ या पूरी रिपोर्ट पेस्ट करें। Pull request भी कर सकते हैं।

GitHub Issues, pull requests और संलग्न फ़ाइलें सार्वजनिक हैं और आपके खाते से जुड़ी हैं। रिपोर्ट ID आपको गुमनाम नहीं बनाती।

ये आपकी बताई हुई आदतें और राय हैं। उद्धरण की अनुमति A05 में है। एक ही भागीदारी के दोनों फ़ॉर्म रिपोर्ट ID से जोड़ें।
