# 开放协作研究方案 / Open collaborative protocol

本项目通过统一的两版问卷收集真实 AI 使用任务报告，再形成描述、关联分析和文字案例。完整实施与分析方案见[中文源稿](protocol/20261026-mbti-ai-use-protocol/zh.qmd)及[英文源稿](protocol/20261026-mbti-ai-use-protocol/en.qmd)。操作流程见[问卷设计说明](QUESTIONNAIRE_DESIGN.md)。

本次公开版本是试填研究方案，不是已完成的人格绩效比较。网站与仓库分别提供阅读和协作入口；不上传整个本地论文工作区。

This project uses two fixed questionnaire forms to collect reports of real AI tasks, followed by descriptions, association analyses, and narrative cases. The linked Chinese and English manuscripts provide the complete implementation and analysis protocol. See the [workflow guide](QUESTIONNAIRE_DESIGN.en.md) for participation.

This release is a pilot protocol, not a completed personality/performance comparison. The site provides reading access and the repository supports collaboration; the wider local research workspace is not published.
